# Задача 2. Проверка цен конкурентов

Приложение на Python и Streamlit автоматически определяет, пригодна ли цена конкурента для дальнейшего использования.

## Доступно по ссылке

https://lenta-test-assignment-botkin.streamlit.app/

## Запуск локально

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Как пользоваться

1. Загрузи файл `.xlsx` и выбери лист с данными. Если в книге есть лист «Данные», он выбран по умолчанию.
2. Нажми «Запустить обработку».
3. Посмотри краткую статистику обработки, очищенный набор данных с ценами, которые прошли проверку, и список исключённых наблюдений с причиной. Обе таблицы можно скачать отдельно в CSV.

## Правила проверки

- Регулярная и акционная цены конкурента должны быть заполнены и содержать конечные числа больше нуля.
- При полном совпадении строк первое наблюдение проходит дальнейшую проверку, а остальные исключаются как точные дубли.
- Если сработало несколько правил, для строки указывается первая причина исключения.
